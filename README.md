# Bảng thông tin cho Kindle Basic 10

## Cách làm (làm một lần, khoảng 10 phút)
1. Tạo tài khoản https://github.com (miễn phí).
2. Bấm **New repository**, đặt tên `kindle-dash`, chọn **Public**, bấm Create.
3. Bấm **uploading an existing file**, kéo cả thư mục này vào (giữ nguyên thư mục `.github/workflows`), bấm **Commit**.
4. Vào tab **Actions** -> chọn **Tạo ảnh Kindle** -> **Run workflow**. Chờ khoảng 1 phút.
5. Khi xong, trong kho sẽ có file `kindle.png`. Link ảnh dạng:
   `https://raw.githubusercontent.com/TÊN_BẠN/kindle-dash/main/kindle.png`
6. Mở link đó trên điện thoại để xem ảnh. Đây là link Kindle sẽ tải về.

Từ đó, GitHub tự cập nhật ảnh mỗi giờ.

## Nếu một mục báo "— chưa lấy được —"
Mở tab Actions, bấm vào lần chạy gần nhất, xem dòng "vàng lỗi" / "xăng lỗi" rồi gửi cho Claude.
